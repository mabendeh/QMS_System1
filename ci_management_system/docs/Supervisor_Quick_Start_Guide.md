# Supervisor Quick-Start Guide
**C.H. Guenther & Son, Duncanville: Supervisor Productivity & CI Management System**

This page covers what you need to run your project and get ready for the weekly WOR meeting.
The full guide is on the workbook tab **12 User Guide**.

---

## Who does what

| Role | Responsibility |
|---|---|
| **Supervisor (Project Leader)** | Leads the project and owns it. Each project has **one** primary owner who is accountable. |
| **Co-Owner / team members** | Support the leader. Production, Maintenance, Warehouse and cross-functional supervisors all take part. |
| **CI Manager (Moe Abendeh)** | Coaches, facilitates and supplies the tools. Reviews charters and data quality. |
| **Finance (incl. Randy)** | Validates financial benefits. **Only Finance-approved savings count as verified.** |

## Cell colours

* **Yellow cell with a navy header**: you type here or pick from the dropdown.
* **Gray cell with a gray header**: a formula. It is locked, so you can't overwrite it.
* Hover over any column header to see what it means.
* If you don't know a value, **leave it blank.** Never type 0 for missing data. Blank cells show **N/A** and get flagged for follow-up.

## The 10 steps

1. **Open the master file** from the approved SharePoint/Teams location. Don't email copies.
2. **02 Project Register**: filter *Project Leader* to your name.
3. **Complete your row**: department, area, shift, sponsor, start and target dates, primary KPI, unit, and the **measured** baseline and target.
4. **03A Charter Records**: write the business problem, scope, current condition, SMART objective, stakeholders, responsibilities, benefits, constraints and risks.
   To view or print the charter, go to **03 Project Charter** and pick your Project ID.
5. **04 Action Tracker**: add one row per action and give each action **one** accountable owner and a due date.
   Set *Milestone = Yes* on key milestones.
6. **When an action is done**, set **Status = Complete *and* enter the Completed Date**. You need both for the action to count.
7. **Evidence**: save the file in the project's SharePoint/Teams folder, click *Copy link*, then add a row to **10 Evidence Register** with the Project ID and Action ID.
   Excel stores the link only, not the file.
8. **Before every WOR**: in **06A WOR Weekly Updates**, add **one row per project per week**. Fill in work completed, next-week commitments, the measured KPI actual, risks, support needed and any decision you need from leadership.
9. **Savings**: enter benefit lines in **05 Financial Savings** with the data source and your assumptions, and set them to *Not Submitted*. Then ask Finance to review.
   Don't enter *Realized Savings*; Finance enters that.
10. **Check your project**: look at **06 Weekly WOR Report** and the dashboard. Clear any of these flags you can before the meeting:
    * OVERDUE
    * MISSING EVIDENCE
    * STALE
    * N/A

## Rules that keep the numbers honest

* **Action completion is counted, not estimated.** It equals completed actions divided by actions that aren't cancelled.
  Your "% complete" estimate is for discussion only and never feeds a KPI.
* **Recovered changeover minutes are capacity, not cash.** They become dollars only when Finance confirms a real output or cost benefit.
* **Forecast savings** are estimates. **Verified savings** are Finance-approved amounts only.
* Don't sort or delete rows in the data sheets. To remove an item, set its Status to **Cancelled**. Filtering is safe.
* Supervisors are developed, not ranked. Savings dollars are **not** part of the development rubric.
